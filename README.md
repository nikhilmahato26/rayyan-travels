# Rayyan Travels & Cab Service

A complete, production-ready travel and cab booking website for **Rayyan Travels & Cab Service**, serving Navsari and Surat, Gujarat, India.

Built with **React 18+**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **React Hook Form / Zod**.

---

## 🚗 Features

- **Real Fleet Showcasing:** Features real vehicle photographs of Rayyan Travels' Toyota Rumion (Navsari RTO permit) alongside Force Urbania, Toyota Innova Crysta, and Kia vehicles.
- **Featured Rental Cab Service:** Prominently highlights local, outstation, airport, event, and group cab rentals.
- **Direct Booking Integration:** Fast enquiry forms validated with Zod that generate formatted, rich WhatsApp messages directly to the primary business phone.
- **Airport Transfers:** Tailored airport pickup, drop, and round-trip transport options.
- **10 Core Travel Services:** Airport transfers, rental cabs, city cabs, outstation trips, sightseeing, tour packages, corporate rides, weddings, and group travel.
- **Mobile Sticky Action Bar:** Quick call, WhatsApp, and booking access on mobile devices.
- **SEO & Structured Data:** Semantic HTML, Open Graph tags, and Schema.org `TaxiService` LocalBusiness JSON-LD markup.
- **Strict Claims Policy:** Zero invented pricing, hourly packages, km rates, or unverified claims.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/nikhilmahato26/rayyan-travels.git

# Navigate to the project directory
cd rayyan-travels

# Install dependencies
npm install --legacy-peer-deps
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```
